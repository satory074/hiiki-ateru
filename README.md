# 12球団当て

知っている選手や球場の名物を答えていくと、その偏りから、あなたの贔屓のプロ野球球団を当てる非公式のファンメイドゲームです。
贔屓がない人、2球団ある人も当てます。

- 遊ぶ: https://satory074.github.io/hiiki-ateru/
- しくみと、答え合わせの集計で保存するもの・しないもの: https://satory074.github.io/hiiki-ateru/about/

NPB・各球団とは関係ありません。球団ロゴ・選手写真・応援歌の歌詞は使っていません。
開発の手順と構成は [CLAUDE.md](CLAUDE.md) にあります。
